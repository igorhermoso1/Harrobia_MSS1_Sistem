~/3-gaia/1-virtualbox-zer-da

1. Zer da VirtualBox?

Ordenagailu bat zure ordenagailuaren barruan.

VirtualBox doako programa bat da, zure ordenagailuaren barruan beste ordenagailu «simulatu» batzuk sortzeko aukera ematen duena. Simulatutako ordenagailu horiei makina birtual deritze.

Makina birtual bakoitzak bere RAM memoria, prozesadorea, diskoa eta sistema eragilea ditu, baina ez dira benetakoak: zure ordenagailuaren baliabideen zati bat «maileguan» hartzen dute. Horregatik, makina birtualean egiten duzun guztia bertan geratzen da, eta ez dio zure benetako ordenagailuari eragiten.

Zertarako erabiliko dugu? Hainbat sistema eragile aldi berean edukitzeko (Ubuntu, Windows, Windows Server), probak egiteko eta sareak muntatzeko, benetako ordenagailurik hautsi edo formateatu gabe.

Oinarrizko kontzeptuak

KontzeptuaZer da, hitz gutxitan
Sistema ostalaria (anfitrión / host)Zure benetako ordenagailua eta haren sistema eragilea, VirtualBox instalatuta duena.
Sistema gonbidatua (invitado / guest)Makina birtualaren barruan instalatzen duzun sistema eragilea (Ubuntu, Windows…).
ISO irudiaSistema eragilearen instalazio-DVDa, fitxategi bakar batean (.iso). Makinaren DVD birtualean «sartzen» da.
Disko gogor birtuala (.vdi)Makinaren diskoa. Zure ordenagailuan fitxategi handi bat besterik ez da.
Host teklaEskuineko Ctrl tekla. Sagua makinaren barruan «harrapatuta» geratzen bada, sakatu tekla hau askatzeko.

2. Hasi aurretik: egiaztapen-zerrenda

Lau gauza hauek prest egon behar dira lehenengo makina sortu aurretik.

  • VirtualBox 7.2 instalatuta. Bertsio zehatza ikusteko: Laguntza ▸ VirtualBox-i buruz (Ayuda ▸ Acerca de VirtualBox).
  • Makina bakoitzaren ISO fitxategia deskargatuta, eta badakizu non gorde duzun.
  • Birtualizazioa gaituta ordenagailuaren BIOS/UEFIan (Intel VT-x edo AMD-V). Gaituta ez badago, VirtualBoxek errore bat emango du makina piztean.
  • Leku librea diskoan: zazpi makinentzat 150 GB inguru.
Aholkua: Zure ordenagailuak 8 GB RAM edo gutxiago badu, piztu makina birtual bakarra aldi berean.
Garrantzitsua: Kutxa ilunetako komandoak letraz letra idatzi behar dira: espazioak, gidoiak (-) eta letra larri/xeheak barne. Akats txiki batek komandoa hondatzen du.

~/3-gaia/3-extension-pack

3. Extension Pack: zer den eta nola instalatu

Zure ordenagailuan instalatzen da, behin bakarrik, eta makina guztiek erabil ditzakete haren funtzioak.

Extension Pack-a VirtualBoxi funtzio gehigarriak ematen dizkion paketea da. Ostalarian instalatzen da (zure ordenagailuan), behin bakarrik. Doakoa da erabilera pertsonal eta hezkuntzarako (PUEL lizentzia).

FuntzioaZer ahalbidetzen du
Urruneko mahaigaina (VRDP)Makina birtuala beste ordenagailu batetik kontrolatzea, urruneko mahaigain-programa batekin.
Web-kamera partekatuaZure ordenagailuko web-kamera makina birtualaren barruan erabiltzea.
Diskoen enkriptatzea (AES)Disko birtuala pasahitz batekin babestea.
PXE abioa (Intel sare-txartelak)Makina sare bidez abiaraztea, diskorik edo ISOrik gabe.
Oharra: VirtualBox 7.0 bertsiotik aurrera, USB 2.0 eta USB 3.0 gailuen euskarria oinarrizko programan dago jada. Ez duzu Extension Pack-ik behar horretarako.

Nola instalatu

  1. Begiratu zure VirtualBoxen bertsio zehatza: Laguntza ▸ VirtualBox-i buruz (adibidez, 7.2.20).
  2. Joan www.virtualbox.org/wiki/Downloads orrira eta deskargatu VirtualBox Extension Pack. Fitxategiaren luzapena .vbox-extpack da.
  3. Egin klik bikoitza deskargatutako fitxategian. VirtualBox irekiko da eta instalatzeko galdetuko dizu: sakatu Instalatu.
  4. Irakurri lizentzia, jaitsi testuaren amaieraraino eta sakatu Onartu. Administratzaile-baimena eskatzen badizu, onartu.
  5. Egiaztatu: Fitxategia ▸ Tresnak ▸ Extension Pack Manager atalean «Oracle VirtualBox Extension Pack» agertu behar da.
Garrantzitsua: Extension Pack-aren bertsioak eta VirtualBoxenak berdinak izan behar dute. VirtualBox eguneratzen duzun bakoitzean, eguneratu Extension Pack-a ere. Zure VirtualBox ez bada azken bertsioa, bilatu zurea «Download_Old_Builds_7_2» orrian.

4. Guest Additions: zer dira eta zer eskaintzen dute

Makina birtualaren barruan instalatzen diren gidari eta programa txikiak.

Guest Additions-ei esker, sistema gonbidatuak «badaki» VirtualBoxen barruan dagoela, eta askoz hobeto lan egiten du zure ordenagailuarekin batera.

Arrastatu eta jareginFitxategiak saguarekin pasatzea ordenagailutik makinara (Windowsen, batez ere).
Karpeta partekatuakZure ordenagailuko karpeta bat makinaren barruan ikustea.
Saguaren integrazioaSagua libre mugitzen da makinaren eta zure ordenagailuaren artean, Host tekla sakatu gabe.
Ordu-sinkronizazioaMakinaren ordua zure ordenagailuarenarekin bat etortzen da.
Grafiko hobeakLeihoak eta animazioak arinago mugitzen dira.

5. Makina birtual bat sortzea

Urrats hauek berdinak dira zazpi makinetan; aldatzen direnak balioak dira.

1. urratsa · Izena eta ISO irudia

  • Ireki VirtualBox eta egin klik Berria (Nueva) botoian.
  • Izena: idatzi izen argi bat (adibidez, Ubuntu 22.04 edo Windows 11 Pro).
  • Karpeta: utzi lehenetsita datorrena.
  • ISO irudia: goitibeherako menuan hautatu Beste bat… eta bilatu deskargatu duzun ISO fitxategia.
  • Mota eta Bertsioa: VirtualBoxek ISOtik detektatzen ditu. Egiaztatu zuzenak direla (adibidez, «Ubuntu (64-bit)»).
  • Markatu Alde batera utzi zaindu gabeko instalazioa laukitxoa eta sakatu Hurrengoa.
Zergatik markatu laukitxo hori? Markatu gabe, VirtualBoxek sistema bere kabuz instalatzen du, zuk ezer erabaki gabe. Gainera, Ubuntun sortzen duen erabiltzaileak ez du administratzaile-baimenik (sudo) izaten. Laukitxoa markatuta, instalazioa zuk kontrolatzen duzu urratsez urrats.

2. urratsa · RAM memoria eta prozesadoreak

  • Oinarrizko memoria: arrastatu barra beheko taulako baliora.
  • Prozesadoreak: makinari emango dizkiozun CPU nukleoak (2).
  • Mantendu beti barraren eremu berdearen barruan, zure ordenagailua ez moteltzeko.

3. urratsa · Disko gogor birtuala

  • Hautatu Sortu disko gogor birtual bat orain.
  • Diskoaren tamaina: idatzi taulako GBak.
  • Ez markatu «Aurrez esleitu tamaina osoa». Horrela diskoa dinamikoa izango da: hasieran txikia da eta, datuak gehitu ahala, hazi egiten da.

4. urratsa · Azken doikuntza eta lehen abioa

  • Konfigurazioa ▸ Pantaila ▸ Bideo-memoria: jarri 128 MB. Ez gaitu 3D azelerazioa. Sakatu Ados.
  • Sakatu Hasi (gezi berdea). Makina piztuko da eta instalatzailea ISOtik abiatuko da.
Gogoratu: Sagua makinaren barruan harrapatuta geratzen bada, sakatu eskuineko Ctrl tekla (Host tekla).

6. Ubuntu instalatzea

Bi instalatzaile daude: zaharra (18.04, 20.04 eta 22.04) eta berria (24.04).

A · Ubuntu 18.04, 20.04 eta 22.04

  1. Aukeratu hizkuntza eta sakatu Instalatu Ubuntu.
  2. Teklatua: «Spanish» / «Español» ▸ Jarraitu.
  3. Eguneraketak eta bestelako softwarea: aukeratu Instalazio normala. Ez markatu «Deskargatu eguneraketak»: instalazioa azkarragoa izango da.
  4. Instalazio mota: Ezabatu diskoa eta instalatu Ubuntu ▸ Instalatu orain ▸ Jarraitu.
  5. Kokapena: Madrid ▸ Jarraitu.
  6. Nor zara?: zure izena, ordenagailuaren izena, erabiltzaile-izena eta pasahitza. Idatzi pasahitza nonbait, ahaztu ez dezazun.
  7. Amaitzean, sakatu Berrabiarazi orain. «Please remove the installation medium» mezua agertzen bada, sakatu Enter.
Lasai: «Ezabatu diskoa» aukerak disko birtuala bakarrik ezabatzen du (hutsik dago). Zure ordenagailuko datuak ez dira ukitzen.

B · Ubuntu 24.04 (instalatzaile berria)

  1. Hizkuntza ▸ Hurrengoa. Irisgarritasuna ▸ Hurrengoa.
  2. Teklatua: «Spanish» ▸ Hurrengoa. Sarea: utzi kable bidezko konexioa ▸ Hurrengoa.
  3. Instalatu Ubuntu ▸ Instalazio interaktiboa ▸ Aukeraketa lehenetsia.
  4. Hirugarrenen softwarea: ez markatu ezer ▸ Hurrengoa.
  5. Ezabatu diskoa eta instalatu Ubuntu ▸ Hurrengoa.
  6. Sortu zure kontua (izena, ordenagailuaren izena, pasahitza) ▸ ordu-zona: Madrid ▸ Instalatu.
  7. Amaitzean: Berrabiarazi orain eta sakatu Enter eskatzen badu.
Oharra: Lehen saioa hastean «Software-eguneratzailea» leihoa ager daiteke. Sakatu Gogorarazi geroago Guest Additions-ak instalatu arte.

7. Guest Additions Ubuntun

Lau Ubuntu bertsioetan metodo bera: bost urrats.

1Eguneratuapt update
2Garbituapt purge
3Tresnakapt install
4CDa + instalatuVBoxLinuxAdditions
5Berrabiarazieta egiaztatu
Zergatik behar dira hainbeste tresna? Guest Additions-ek moduluak sortu behar dituzte: kernelaren (sistemaren «bihotzaren») pieza txikiak. Horretarako, konpiladore bat behar da (testuan idatzitako programa exekutagarri bihurtzen duen tresna) eta zure kernelaren goiburuak (headers, kernelaren «planoak»). Horietako bat falta bada, instalazioak huts egiten du.
Oharra: Guest Additions-ak instalatu arte ez dago arbel partekaturik: komandoak eskuz idatzi behar dira. Terminala irekitzeko: Ctrl + Alt + T. sudo erabiltzean pasahitza eskatuko dizu; idaztean ez da ezer ikusiko (ez izartxorik ere). Normala da: idatzi eta sakatu Enter.

Komandoak, urratsez urrats

1. Eguneratu paketeen zerrenda:

sudo apt update

2. Kendu Ubuntuk berez ekar ditzakeen Guest Additions zaharrak:

sudo apt purge -y virtualbox-guest-utils virtualbox-guest-x11

«is not installed» edo «Unable to locate package» esaten badu, ez dago arazorik: jarraitu.

3. Instalatu beharrezko tresnak (Ubuntu 22.04n gcc-12 ezinbestekoa da):

sudo apt install -y build-essential dkms perl bzip2 tarsudo apt install -y linux-headers-$(uname -r)
Ubuntu 22.04.5: erabili sudo apt install -y build-essential dkms gcc-12 perl bzip2 tar. Haren kernela gcc-12 konpiladorearekin sortu zen, baina build-essential-ek bertsio zaharragoa instalatzen du. Ubuntu 24.04n ez da ezer gehitu behar: build-essential-ek gcc-13 jartzen du jada.

4. Txertatu CDa: Gailuak ▸ Txertatu «Guest Additions» CD irudia. Leiho bat agertzen bada automatikoki exekutatzeko galdetuz, sakatu Utzi. Gero, muntatu eta exekutatu:

sudo mkdir -p /mnt/cdromsudo mount /dev/cdrom /mnt/cdromsudo sh /mnt/cdrom/VBoxLinuxAdditions.run

5. Ubuntu 22.04 eta 24.04n, desgaitu Wayland eta berrabiarazi:

sudo nano /etc/gdm3/custom.confsudo reboot

Fitxategian, bilatu #WaylandEnable=false lerroa, ezabatu hasierako # ikurra eta utzi honela: WaylandEnable=false. Gordetzeko: Ctrl+O eta Enter. Irteteko: Ctrl+X.

Egiaztatu

VBoxControl --versionecho $XDG_SESSION_TYPE

Lehenengoak VirtualBoxen bertsio bera erakutsi behar du (adibidez, 7.2.20r…), eta bigarrenak x11. Gero, aldatu leihoaren tamaina saguarekin: mahaigainak berehala egokitu behar du.

8. Windows instalatzea

Windows 10, Windows 11 Pro eta Windows Server 2019 instalatzaileak oso antzekoak dira.

Urrats komunak

  1. «Press any key to boot from CD or DVD...» agertzen bada, sakatu edozein tekla berehala.
  2. Hizkuntza, ordua eta teklatua ▸ Hurrengoa ▸ Instalatu orain. Windows 11n: aukeratu «Instalatu Windows 11» eta markatu dena ezabatuko dela onartzeko laukitxoa.
  3. Produktu-gakoa: sakatu Ez daukat produktu-gakorik.
  4. Aukeratu edizioa eta onartu lizentzia.
  5. Instalazio mota: Pertsonalizatua: instalatu Windows soilik. Windows 11n urrats hau ez da agertzen.
  6. Hautatu Esleitu gabeko espazioa, 0 unitatea ▸ Hurrengoa (Windows 11n: Instalatu).
  7. Itxaron. Makina hainbat aldiz berrabiaraziko da; ez sakatu teklarik.
Gogoratu: Windowsen sare-txartelak ikusteko eta konfiguratzeko: Windows + R ▸ idatzi ncpa.cpl ▸ Enter.

Windows 10 · kontu lokala sortu (Microsoft konturik gabe)

  1. Konfigurazioaren lehen pantaila agertzean (eskualdea aukeratzeko), deskonektatu makinaren sarea: Gailuak ▸ Sarea ▸ Konektatu sare-egokigailua eta kendu marka.
  2. Sarerik gabe, Windowsek beste aukera batzuk erakutsiko ditu: Ez daukat Internetik ▸ Jarraitu konfigurazio mugatuarekin. Pro edizioan «Lineaz kanpoko kontua» ere ager daiteke.
  3. Idatzi erabiltzaile-izena, pasahitza eta hiru segurtasun-galderak.
  4. Pribatutasun-aukerak: desaktibatu guztiak ▸ Onartu.
  5. Mahaigaina agertzean, konektatu berriro sarea (menu bera, markatu aukera).

Windows 11 Pro · EFI, Secure Boot eta TPM 2.0

Windows 11ren ISOa hautatzean, VirtualBoxek automatikoki gaitzen ditu segurtasun-aukerak. Hala ere, egiaztatu lehen aldiz piztu aurretik: Konfigurazioa ▸ Sistema ▸ Plaka nagusia atalean, Gaitu EFI markatuta, Gaitu Secure Boot markatuta (laukitxo bereizia da) eta TPM gailua: v2.0.

TeknologiaAzalpen sinplea
TPM 2.0Segurtasun-txip txiki bat (fisikoa edo birtuala). Pasahitzak eta gakoak gordetzen eta zifratzen ditu, inork lapurtu ez ditzan.
Secure Boot (abiarazte segurua)Ordenagailua software fidagarriarekin bakarrik pizten dela bermatzen du, Windows baino lehen abiarazi nahi duen birus edo malwarea blokeatuz.

Kontu lokala Windows 11n: hiru metodo

  1. 1. metodoa: posta elektronikoa eskatzen duen pantailan, sakatu Shift + F10 kontsola beltza irekitzeko eta idatzi: start ms-cxh:localonly Leiho bat irekiko da erabiltzaile lokala sortzeko. Bete datuak eta jarraitu.
  2. 2. metodoa (1.ak ezer egiten ez badu): Lanerako edo ikastetxerako konfiguratu ▸ Saioa hasteko aukerak ▸ Domeinu batera batu horren ordez. Pro edizioan bakarrik dago.
  3. 3. metodoa (azken aukera): amaitu instalazioa Microsoft kontu batekin eta gero sortu erabiltzaile lokala Ezarpenak ▸ Kontuak atalean.
Oharra: Windows 11ren bertsio berrienetan Microsoft trikimailu hauek mugatzen ari da. Horregatik daude hiru metodo.

Windows Server 2019

Garrantzitsua: Edizioa aukeratzean, hautatu izenean (Experiencia de escritorio) duena, adibidez: Windows Server 2019 Standard Evaluation (Experiencia de escritorio). Bestela, «Server Core» instalatuko da: mahaigainik gabe, komando-lerroa bakarrik.
  1. Administratzailearen pasahitza konplexua izan behar du: gutxienez 8 karaktere, eta hauetatik hiru: letra larria, letra xehea, zenbakia eta ikurra (adibidez, Harrobia2026!).
  2. Saioa hasteko, Windows Serverrek Ctrl+Alt+Supr eskatzen du. Makina birtualean sakatu Host + Supr (eskuineko Ctrl + Supr), edo menuan: Sarrera ▸ Teklatua ▸ Txertatu Ctrl-Alt-Supr.
  3. Zerbitzari-kudeatzailea automatikoki irekiko da. Normala da; itxi dezakezu.
Oharra: Ebaluazio-bertsioak 180 egun irauten ditu.

9. Guest Additions Windowsen

Windows 10, Windows 11 eta Windows Server 2019n prozedura bera da: ez dago komandorik, instalatzaile grafikoa baizik.

  1. Makina piztuta eta saioa hasita: Gailuak ▸ Txertatu «Guest Additions» CD irudia.
  2. Ireki fitxategi-arakatzailea (Windows + E) ▸ Ekipo hau ▸ CD unitatea (D:) VirtualBox Guest Additions.
  3. Egin klik bikoitza VBoxWindowsAdditions.exe fitxategian ▸ Bai baimena eskatzen badu.
  4. Next ▸ Next ▸ Install. Utzi lehenetsitako osagaiak.
  5. Gidariak instalatzeko galdetzen badu, markatu «Oracle-ren softwarea beti fidagarritzat hartu» ▸ Instalatu.

11. Kali Linux

Hemen ez da CDa erabiltzen: Kaliren biltegiko paketea instalatzen da.

Garrantzitsua: Kalik diskoan instalatuta egon behar du. «Live» moduan (ISOtik zuzenean abiarazita, instalatu gabe) eguneraketak RAMa betetzen du, makina izoztu egiten da eta berrabiaraztean dena galtzen da.
Oharra: Kaliren VirtualBox irudi aurre-prestatuan, erabiltzailea eta pasahitza kali / kali dira. Guest Additions-ak automatikoki instalatuta egon daitezke; hala ere, egin urrats guztiak: ziurtatzen dute bertsio zuzena dagoela eta ez dagoela nahasketarik.
1Eguneratufull-upgrade + reboot
2GarbituCDko GA zaharrak
3Instalatuvirtualbox-guest-x11
4Berrabiarazieta egiaztatu

1. Paketeen zerrenda eguneratu:

sudo apt update

Gako batekin lotutako errorea agertzen bada («Missing key 827C…ED65462EC8D5E4C5», «NO_PUBKEY» edo «EXPKEYSIG»), Kaliren sinadura-gakoa zaharkituta dago. Instalatu berria eta errepikatu:

sudo wget https://archive.kali.org/archive-keyring.gpg -O /usr/share/keyrings/kali-archive-keyring.gpgsudo apt update

2. Sistema guztiz eguneratu eta berrabiarazi:

export DEBIAN_FRONTEND=noninteractive NEEDRESTART_MODE=a APT_LISTCHANGES_FRONTEND=nonesudo -E apt-get -y -o Dpkg::Options::=--force-confold dist-upgradesudo reboot
Zergatik? Kaliren dokumentazio ofizialak dio Guest Additions-ak instalatu aurretik sistema guztiz eguneratuta egon behar duela: paketearen eta kernelaren bertsioek bat etorri behar dute. Lehen aldian 30 minutu ere behar ditzake.

3. CDko Guest Additions zaharrak kendu (badaude):

ls /opt | grep VBoxGuestAdditions

Ezer ez bada agertzen, ondo: jarraitu. VBoxGuestAdditions-7.x.x bezalako lerro bat agertzen bada, desinstalatu eta berrabiarazi:

sudo sh /opt/VBoxGuestAdditions-*/uninstall.shsudo reboot

4. Paketea dagoela egiaztatu eta instalatu:

apt policy virtualbox-guest-x11sudo apt install -y --reinstall virtualbox-guest-x11

Candidate: lerroan bertsio bat agertu behar da (adib. 7.2.16-dfsg-1). Pakete honek virtualbox-guest-utils ere instalatzen du. Ez da CDrik behar, ezta kernel-goiburuak ere: Kaliren kernelak dagoeneko baditu Guest Additions-en moduluak.

Candidate: (none) agertzen bada, biltegien zerrendan contrib atala falta da. Konpondu eta itzuli urrats honen hasierara:

echo "deb http://http.kali.org/kali kali-rolling main contrib non-free non-free-firmware" | sudo tee /etc/apt/sources.listsudo apt update

5. Berrabiarazi eta egiaztatu:

sudo rebootlsmod | grep vboxsystemctl status virtualbox-guest-utils

Lehenengoak vboxguest eta vboxsf lerroak erakutsi behar ditu. Bigarrenak active (running) erakutsi behar du berdez. Irteteko: q tekla.

Garrantzitsua: Kalin ez exekutatu VirtualBoxen CDko VBoxLinuxAdditions.run. Biltegiko paketearekin nahastuz gero, akatsak sortzen dira.
Oharra: Kaliko paketearen bertsioa eta zure VirtualBoxena ez dira zertan berdin-berdinak izan (adib. 7.2.16 eta 7.2.20). Normala da eta ondo funtzionatzen du.

12. Funtzioak aktibatu eta erabili

Guest Additions-ak instalatuta, hona hemen zer gaitu makina bakoitzean.

A · Arbel partekatua eta arrastatu-jaregin

Makina piztuta dagoela, VirtualBox leihoaren goiko menuan:

  • Gailuak ▸ Arbel partekatua ▸ Bi norabidekoa
  • Gailuak ▸ Arrastatu eta jaregin ▸ Bi norabidekoa

Proba: kopiatu testu bat zure ordenagailuan (Ctrl+C) eta itsatsi makinan (Ctrl+V; terminalean Ctrl+Shift+V). Funtzionatzen badu, Guest Additions-ak ondo daude.

Oharra: Linux makinetan arrastatu eta jaregin mugatua da eta ez du beti funtzionatzen. Fitxategiak pasatzeko, erabili karpeta partekatua: seguruagoa da.

B · Karpeta partekatua

  1. Zure ordenagailuan, sortu karpeta bat (adib. C:\Partekatua Windowsen edo ~/Partekatua Linuxen).
  2. VirtualBoxen, makina piztuta: Gailuak ▸ Karpeta partekatuak ▸ Karpeta partekatuen ezarpenak ▸ karpeta-ikonoa + ikurrarekin.
  3. Karpetaren bidea: aukeratu sortutako karpeta. Karpetaren izena: Partekatua. Markatu Muntatu automatikoki eta Iraunkorra egin. Muntatze-puntua hutsik utzi ▸ Ados.
  4. Makinan, gehitu zure erabiltzailea vboxsf taldera eta berrabiarazi: sudo usermod -aG vboxsf $USERsudo reboot
  5. Berrabiarazi ondoren, karpeta hemen dago: /media/sf_Partekatua. Fitxategi-arakatzailean ere agertzen da.

C · Argazkiak (instantáneas)

Aholkua: Makina bakoitza prest dagoenean, egin argazki bat: Makina ▸ Hartu argazkia, izena: Guest Additions instalatuta. Zerbait hondatzen baduzu, egoera horretara itzul zaitezke minutu batean.
