Python programazioa

Aldagaiak, eragiketak, baldintzak, begiztak eta funtzioak. Hemen teoria irakurri, adibideak exekutatu eta ariketak egin ditzakezu — Python instalatu gabe, nabigatzailean bertan.

0. Python martxan jartzea

Programatzea ordenagailuari zer egin behar duen esatea da, berak ulertzen duen hizkuntzan eta ordena zehatz batean.

Ordenagailua azkarra da, baina ez du ezer asmatzen: zuk esandakoa egiten du, hitzez hitz. Gida honen helburua oinarrizko egiturak ulertzea da: aldagaiak, kalkuluak, erabakiak, errepikapenak eta funtzioak.

Python kodea testu arrunta da, .py luzapena duen fitxategi batean gordeta. Gelan Visual Studio Code erabiliko dugu; orri honetan, aldiz, kodea hemen bertan exekutatuko duzu. Pythonek lerroak goitik behera exekutatzen ditu, banan-banan. print()-ek parentesien artean jartzen zaiona pantailan idazten du.

Prestaketa

  1. Instalatu Python. Windowsen, instalatzailean markatu «Add Python to PATH» laukitxoa hasi aurretik.
  2. Ireki Visual Studio Code eta instalatu Python luzapena: ezkerreko barrako lauki-ikonoa, idatzi Python, eta Install.
  3. Sortu karpeta bat zure ariketetarako eta ireki VS Coden: File › Open Folder.

Lehen programa

Sortu fitxategi berri bat eta gorde lehena.py izenarekin (luzapena .py izatea ezinbestekoa da). Exekutatu: eskuineko goiko aldeko ▶ botoia, edo Ctrl + F5. Emaitza beheko paneleko terminalean agertzen da.

print("Kaixo mundua!")
print("Python ikasten hasi naiz.")

Errore-mezuak

Akatsak etengabe agertuko zaizkizu, eta hori normala da. Garrantzitsuena azken lerroa da: errore-mota eta azalpena. Gainera, zein lerrotan gertatu den esaten dizu. Probatu:

print(izena)

NameError: «izena» izeneko ezer ez dago definituta, hau da, aldagai hori ez duzu sortu.

Kontuan: 7. atalean ikusiko dugun match-case egitura Python 3.10etik aurrera bakarrik dago. Terminalean python --version idatziz ikusiko duzu zein bertsio duzun; Windowsen python ez badabil, probatu py.

1. Aldagaiak

Aldagai bat informazioa gordetzeko lekua da: etiketa bat duen kutxa bat.

Barruan zerbait sartzen duzu, eta kanpoan izen bat idazten diozu gero aurkitzeko. Aldagairik gabe, programa batek ezingo luke ezer gogoratu lerro batetik bestera. Izena idatzi, berdin ikurra jarri, eta balioa; ez duzu ezer deklaratu behar aldez aurretik.

izena = "Ane"
adina = 16

Berdin ikurrak ez du «berdina da» esan nahi. x = 5 agindu bat da: «gorde 5 x deitzen den kutxan». Eskuinetik ezkerrera irakurtzen da: adina ← 16. Hortaz, 16 = adina idaztea errorea da.

Komekin bereizita jar daitezke testua eta aldagaiak; Pythonek hutsune bat jartzen du koma bakoitzaren tokian. Balio berri bat gordetzean, zaharra galdu egiten da, eta aldagaia erabili aurretik sortu behar duzu.

izena = "Mikel"

3. Sarrera eta irteera: input eta print

Programa erabilgarri batek erabiltzaileari galdetzen dio eta erantzunarekin lan egiten du.

Irteera: print() eta f-string

Testua eta aldagaiak asko nahasten dituzunean, f-stringa erosoagoa da: komatxoen aurretik f bat jarri eta aldagaiak giltzen artean sartu. Barruan eragiketak ere egin daitezke.

izena = "Ane"
adina = 16
print(f"{izena}k {adina} urte ditu")
print(f"Hamar urte barru {adina + 10} izango ditu")

Sarrera: input()

input() funtzioak programa gelditu eta erabiltzaileak zerbait idatzi eta Enter sakatu arte itxaroten du. Parentesien arteko testua galdera da; ez ahaztu amaieran hutsune bat uztea.

izena = input("Nola duzu izena? ")
print("Kaixo,", izena)
Arau garrantzitsuena: input() beti testua da. Erabiltzaileak 16 idazten badu ere, aldagaiak "16" dauka, ez 16. Horregatik ezin da zuzenean kalkulurik egin: TypeError.

Eragiketen ordena eta round()

Lehenengo parentesiak, gero berreturak, gero biderketak eta zatiketak, eta azkenik batuketak eta kenketak. Zalantzarik baduzu, jarri parentesiak. round()-en lehen balioa zenbakia da, eta bigarrena zenbat hamartar nahi dituzun.

print(2 + 3 * 4)
print((2 + 3) * 4)
emaitza = 10 / 3
print(emaitza)
print(round(emaitza, 2))
print(round(emaitza))

5. Konparazioak eta eragiketa logikoak

Konparazio baten erantzuna beti da True edo False: bool mota.

= eta == ez dira gauza bera. Ikur batek (=) gordetzen du: adina = 16. Bi ikurrek (==) galdetzen dute: adina == 16 «16 da adina?». Hau da hasiberrien akatsik ohikoena.

Testuak ere konparatu daitezke, eta larriak eta xeheak bereizten dira: "Ane" eta "ane" ez dira berdinak. Konparazio baten emaitza aldagai batean gorde daiteke.

adina = 16
print(adina > 18)
print(adina == 16)
print(10 == "10")
nagusia_da = adina >= 18
print(nagusia_da)

and, or, not

and → ETA: bi baldintzak bete behar dira. or → EDO: bat betetzea nahikoa da. not → EZ: emaitza alderantzikatzen du. Hirurak letra xehez idazten dira.

FalseFalseFalseFalseTrue

Baldintza luze bat ikusten duzunean, ebaluatu zati bakoitza bere aldetik, eta gero konbinatu. Parentesiak erabiltzea komeni da.

adina = 17
baimena = True
sar_daiteke = (adina >= 18) or (adina >= 16 and baimena)
print(sar_daiteke)
Konparazio bakoitzak bere aldagaia behar du. Pythonen adina > 18 and adina < 65 idazten da; adina > 18 and < 65 errorea da.

6. Baldintzak: if, elif, else

Programek egoeraren arabera jokatu behar dute.

Bi gauza dira ezinbestekoak: baldintzaren ondoren bi puntu (:), eta hurrengo lerroa koskatuta. Baldintza True bada, barruko kodea exekutatzen da; False bada, saltatu egiten da eta programak aurrera jarraitzen du.

adina = 20
if adina >= 18:
    print("Nagusia zara")
print("Programa amaitu da")
Koska: Pythonen arau nagusia. Pythonen ezkerreko hutsuneek erabakitzen dute zer dagoen if baten barruan eta zer ez. Erabili beti 4 hutsune (VS Codek Tab teklarekin egiten du). Blokeko lerro guztiek koska bera izan behar dute, bestela IndentationError. Bi puntuak ahazten badira, SyntaxError.

else eta elif

else-k ez du baldintzarik: gainerako kasu guztietarako da. Beti bata edo bestea exekutatzen da, inoiz ez biak. Bi aukera baino gehiago badaude, elif erabiltzen da; nahi adina jar daitezke.

nota = 7
if nota < 5:
    print("Gutxiegi")
elif nota < 7:
    print("Nahikoa")
elif nota < 9:
    print("Ondo")
else:
    print("Bikain")

Pythonek baldintzak ordenan aztertzen ditu, lehenengotik hasita. Bat betetzen duenean, bere blokea exekutatu eta gainerako guztiak saltatzen ditu. Ordena garrantzitsua da: okerreko ordenan jarrita, emaitza okerra izan daiteke.

Baldintza konbinatuak eta if barruko if

if bat beste if baten barruan jar daiteke; koska bikoiztu egiten da, 8 hutsunera. Askotan and erabiliz sinplifikatu daiteke, baina barruko if-ak mezu zehatzagoak ematen ditu.

adina = 20
txartela = False
if adina >= 18:
    if txartela:
        print("Sartu zaitezke")
    else:
        print("Txartela falta zaizu")
else:
    print("Adinez ez duzu sartzerik")

7. match-case: Pythoneko «switch»

Balio bat balio zehatz askorekin alderatu behar duzunean.

Pythonek aldagaiaren balioa begiratzen du eta bat datorren case-a bakarrik exekutatzen du. Koska bikoitza: case lerroak match-etik 4 hutsunera daude, eta ekintzak case-tik beste 4ra. case _ «beste edozer» da, else-ren parekoa, eta beti azkenean jartzen da. Barra bertikalak (|) hainbat balio elkartzen ditu («edo»).

eguna = 6
match eguna:
    case 1:
        print("Astelehena")
    case 6 | 7:
        print("Asteburua")
    case _:
        print("Egun ezezaguna")

Testuekin ere balio du:

kolorea = input("Zein kolore? ")
match kolorea:
    case "gorria":
        print("Gelditu")
    case "horia":
        print("Kontuz")
    case "berdea":
        print("Aurrera")
    case _:
        print("Kolore hori ez dut ezagutzen")
Erabili match-caseErabili if / elif
Balio zehatzak konparatzeanTarteak konparatzean (nota < 5)
Menu bat programatzeanand, or edo not behar duzunean
Aukera finko asko daudeneanBi aukera bakarrik daudenean
Bertsioaren baldintza: match-case Python 3.10 bertsiotik aurrera bakarrik dago; zaharragoa bada, SyntaxError. Egitura bera if-elif-else erabiliz idatz dezakezu: emaitza berdina da.

8. Begiztak: while

Begizta batek kode zati bat errepikatzen du.

while-ek ordenagailuari esaten dio: «errepikatu kode hau baldintza egia den bitartean». Baldintza exekuzio bakoitzaren AURRETIK begiratzen du; gezurra bihurtzen denean, begizta amaitu eta programak aurrera jarraitzen du. if-ek behin bakarrik begiratzen du; while-ek behin eta berriz.

zenbakia = 1
while zenbakia <= 5:
    print(zenbakia)
    zenbakia += 1
print("Amaitu da")
Begizta orok hiru zati ditu: 1) HASIERAKETA (zenbakia = 1, begizta baino lehen), 2) BALDINTZA (while zenbakia <= 5:), 3) ALDAKETA (zenbakia += 1, begizta barruan). Hasieraketa gabe, NameError. Aldaketa gabe, baldintza beti True izango da: begizta amaigabea (gertatzen bazaizu, Ctrl + C terminalean). Aldaketak baldintzatik hurbildu behar du, ez urrundu.
kontagailua = 5
while kontagailua > 0:
    print(kontagailua)
    kontagailua -= 1
print("Hasi!")

Erabiltzailearekin eta break

Begiztak oso erabilgarriak dira erabiltzaileak zerbait ondo egin arte eskatzeko. Hasierako balioa ("") garrantzitsua da: while-ek aldagaia existitzea behar du lehen aldiz begiratzeko.

pasahitza = ""
while pasahitza != "1234":
    pasahitza = input("Sartu pasahitza: ")
print("Sarbidea onartuta")

break aginduak begizta berehala gelditzen du. while True beti egia denez, begizta berez amaigabea da, eta barruan if batek break egiten du irteteko unea iristen denean.

while True:
    zenbakia = int(input("Zenbaki bat (0 irteteko): "))
    if zenbakia == 0:
        break
    print("Bikoitza:", zenbakia * 2)
print("Agur")
EgituraNoiz begiratzen du baldintzaGutxienez zenbat aldiz
whileHasieran, exekutatu aurretik0 aldiz
do-while (beste lengoaietan)Amaieran, exekutatu ondoren1 aldiz
while True + breakBarruan, zuk nahi duzun tokian1 aldiz

Pythonek ez dauka do-while, baina while True eta break erabiliz berdin-berdin lortzen da.

9. Akumulatzailea eta kontagailua

Itxura berdina dute, baina ez dute gauza bera egiten.

TresnaZertarakoNola handitzen den
AkumulatzaileaBalioak metatzeko (batura)guztira += balioa
KontagailuaZenbat aldiz gertatu den kontatzekokontagailua += 1

Akumulatzailea aurrezki-kutxa bat bezalakoa da: hasieran hutsik dago (0), eta dirua sartzen duzun bakoitzean kopurua handitzen da. Hiru urrats ditu beti: 0an hasieratu, begiztan gehitu, eta amaieran erabili. Begiztan, kontagailuak begizta kontrolatzen du eta akumulatzaileak emaitza metatzen du.

guztira = 0
kontagailua = 0
while kontagailua < 5:
    zenbakia = int(input("Sartu zenbaki bat: "))
    guztira += zenbakia
    kontagailua += 1
print("Batura:", guztira)

Batez bestekoa eta kontagailua baldintzarekin

Batez bestekoa batura zati kopurua da. Kontuz: kopurua 0 bada, ZeroDivisionError; horregatik egiaztatzen da zatitu aurretik.

guztira = 0
kopurua = 0
while kopurua < 3:
    nota = float(input("Sartu nota: "))
    guztira += nota
    kopurua += 1
if kopurua > 0:
    print("Batez bestekoa:", round(guztira / kopurua, 2))

Askotan baldintza bat betetzen dutenak bakarrik kontatu nahi dira. Ohartu koskan: positiboak += 1 if-aren barruan dago, baina kontagailua += 1 kanpoan; barruan jarriz gero, begizta ez litzateke inoiz amaituko zenbaki negatiboekin.

positiboak = 0
kontagailua = 0
while kontagailua < 5:
    zenbakia = int(input("Zenbakia: "))
    if zenbakia > 0:
        positiboak += 1
    kontagailua += 1
print("Positiboak:", positiboak)

«Irten arte» begizta: ez duzu beti zenbat aldiz jakin behar; balio berezi batekin amai daiteke.

guztira = 0
while True:
    kopurua = float(input("Sartu kopurua (0 amaitzeko): "))
    if kopurua == 0:
        break
    guztira += kopurua
print("Aurreztutakoa:", guztira)

10. Funtzioak

Funtzio bat izena duen kode multzo bat da, nahi duzunean exekutatu dezakezuna.

Programak hazten direnean, kode bera behin baino gehiagotan errepikatzen da, eta fitxategia luzeegia bihurtzen da. Funtzioek hori konpontzen dute. Kafe-makina bat bezalakoak dira: botoia sakatu (funtzioari deitu) eta beti gauza bera egiten du. Dagoeneko erabili dituzu: print(), input(), int(), round() eta type().

Sortzea eta deitzea

Hiru zati: def hitza, funtzioaren izena parentesiekin, eta bi puntu. Barruko kodea koskatuta doa. Definitzea ez da exekutatzea: exekutatzeko deitu egin behar zaio, izena eta parentesiak idatzita.

def agurra():
    print("Kaixo!")
    print("Ongi etorri programara")

agurra()
agurra()

Parametroak

Funtzio batek kanpotik datuak jaso ditzake. Parentesien artean jartzen dira, eta parametro deitzen zaie. Balioak definitutako ordena berean jaso behar dira, eta kopuruak bat etorri behar du; bestela, TypeError.

def agurra(izena):
    print(f"Kaixo, {izena}!")

def aurkeztu(izena, adina, herria):
    print(f"{izena}, {adina} urte, {herria}")

agurra("Ane")
aurkeztu("Jon", 17, "Galdakao")

return: emaitza itzultzea

return eta print ez dira gauza bera. print()-ek pantailan idazten du; programak ezin du gero erabili. return-ek balioa itzultzen du: pantailan ez da ezer agertzen, baina balioa gorde eta erabil dezakezu. Araua: funtzioak kalkulatzen badu, return; erakusten badu, print. return exekutatzean funtzioa bertan behera gelditzen da.
def batu_print(a, b):
    print(a + b)

def batu_return(a, b):
    return a + b

x = batu_print(2, 3)
y = batu_return(2, 3)
print("x =", x)
print("y =", y)

Lehenengoak 5 idatzi du, baina ez du ezer itzuli: horregatik x-ek None dauka. Bigarrenak balioa itzuli du eta y-n gorde da.

def bez_kalkulatu(prezioa, tasa):
    return prezioa + (prezioa * tasa)

def tiketa_erakutsi(produktua, prezioa):
    guztira = bez_kalkulatu(prezioa, 0.21)
    print(f"{produktua}: {round(guztira, 2)} euro (BEZa barne)")

tiketa_erakutsi("Koadernoa", 4.5)
tiketa_erakutsi("Motxila", 24.9)
Funtzio barruko aldagaiak funtzio horretakoak dira bakarrik; kanpotik erabiltzen saiatuz gero, NameError. Balio bat kanpora atera nahi baduzu, return. Funtzioak erabili aurretik definitu behar dira: ohitura ona da funtzio guztiak fitxategiaren goialdean jartzea eta programa nagusia azpian.
