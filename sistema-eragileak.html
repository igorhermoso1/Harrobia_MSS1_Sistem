01 · OINARRIAK

Zer da sistema eragilea?

Ordenagailu baten funtsezko softwarea da, hardwarea eta erabiltzailea elkarrekin komunikatzeko bitartekari-lanak egiten dituena.

~/sarrera.md

Ordenagailuaren hardwarea zuzenean erabiltzea oso zaila denez, erabiltzaileen programen eta ordenagailuaren arteko bitartekari-lanak egiten dituen softwarea ezartzen da hardwarearen gainean: hori da sistema eragilea.

Sistema eragileak ordenagailuaren hardware-zehaztasunak ezkutatzen dizkigu, konplexutasunean gal ez gaitezen, eta erabilera erraztuko duten bitartekari grafikoak eskaintzen dizkigu. Horrela sortzen da alegiazko makina kontzeptua: sistema eragileak erabiltzaileari eskaintzen dion ordenagailuaren bista sinplifikatua.

Bi ikuspuntu

Erabileraren ikuspuntutik: ordenagailuaren baliabideak erabiltzeko aukera ematen duen errutina-multzoa da.

Inplementazioaren ikuspuntutik: baliabide horiek modu eraginkorrean erabiltzeko aukera ematen duen software-multzoa da.

Gogoratu: ordenagailua piztean, BIOS softwareak POST (Power On Self Test) autofroga egiten du, hardware-gailuen funtzionamendua ziurtatzeko — horregatik entzuten da pizte-hotsa!

05 · HISTORIA

Sistema eragileen bilakaera historikoa

1940ko hamarkadan ez zegoen sistema eragilerik: hardwarea "eskuz" kudeatu behar zen. Hortik gaur egunera, lau belaunaldi bereizten dira hardwarearen arabera.

~/historia/belaunaldiak.log
Aurrekari batzuk: Charles Babbage matematikariak garatu zuen lehen "konputagailua", baina eragiketa matematiko gutxi batzuk baino ez zituen egiten. Geroago, George Boolek Boole aljebra garatu zuen, eta horrek programazioaren oinarriak ezarri zituen. Sistema eragileen beharra 50eko hamarkadan agertu zen; lehenengoak FSM (Fortran Monitor System) eta IBSYS izan ziren.
1. belaunaldia — 1945/1955

Huts-balbulak eta zulodun panelak

Oraindik ez ziren benetako ordenagailuak: huts-balbulak erabiltzen zituzten eta makina-lengoaian programatzen ziren. Tamaina handikoak, geldoak eta eragiketa matematiko sinpleak baino ez zituzten egiten. Ez dago belaunaldi honetan sistema eragilerik.

2. belaunaldia — 1955/1965

Transistoreak

Transistoreek huts-balbulak ordezkatu zituzten: ordenagailu txikiagoak, merkeagoak eta bero gutxiago isurtzen zutenak. Sistema eragileak lanen arteko trantsizioak azkartzeko diseinatu ziren, eta horrek zatikako prozesaketaren hasiera bultzatu zuen.

3. belaunaldia — 1965/1980

Zirkuitu integratuak

Askotariko programazioa eta askotariko prozesaketa dira ezaugarri nagusiak. Ordenagailu-multzoak kudeatu zituen lehen sistema eragilea IBMren OS/360 izan zen.

4. belaunaldia — 1980tik aurrera

Ordenagailu pertsonalak

Ordenagailu pertsonal eta terminal kontzeptuak zabaldu ziren, bitartekari grafiko sinpleekin batera. 80ko hamarkadaren erdian konputagailu-sareen erabilera hazi zen, eta horrek sareko sistema eragileen eta sistema eragile banatuen beharra agerian utzi zuen.

08 · FAMILIA 1

UNIX eta GNU/LINUX sistema eragileak

60ko hamarkadan hasitako istorio bat, mundu osoko programatzaileen elkarlanak bultzatuta.

~/unix/historia.txt

MULTICS → UNICS → UNIX

1965ean, AT&T Bell laborategiek, General Electricek eta MITek MULTICS sistema eragilean lanean ziharduten. Emaitza eskasa izan zenez, 1969an bertan behera utzi zen, baina etorkizuneko sistema eragileen nondik norakoak definitu zituen.

Proiektu horretan zeuden Dennis Ritchie eta Ken Thompsonek MULTICSen oinarritutako UNICS sistema garatu zuten 1969an. Izen jokoz, UNIX izena jarri zioten. 1973an, C lengoaian berridatzi zuten, eta horrek eramangarri bihurtu zuen. AT&Tk lizentzia doan eskaini zien unibertsitateei, eta Berkeleyko unibertsitateak bere BSD bertsioa plazaratu zuen 1975ean, lehiakide bilakatuz. 1983an, AT&Tk System V Release I plazaratu zuen, estandarra lortzeko.

1993an Novellek AT&Tren Unix System Laboratories saila erosi zuen, eta Kaliforniako unibertsitatearekin izandako auzian, BSDren kode-zatiak System Ven kopiatu zirela frogatu zen.

Linus Torvalds eta LINUXen jaiotza

1991n, 21 urteko ikaslea zen Linus Torvaldsek 386 ordenagailu bat erosi zuen. MINIX erabiltzea erabaki zuen (Andrew S. Tanenbaum irakasleak sortutako UNIX esperimentala), baina ez zituen bere beharrak asetzen. Garai berean, Richard Stallmanek bultzatutako GNU proiektuak (1983, Free Software Foundation) bere nukleoa (HURD) garatzen urte asko behar zituen. Linusek bere nukleo propioa garatu zuen, eta LINUX deitu zion. LINUX nukleoa GNU aplikazioekin batuz, GNU/LINUX sortzen da.

09 · FAMILIA 2

Microsoften sistema eragileak

1975ean sortutako enpresa txiki batetik informatikaren monopoliora.

~/microsoft/historia.txt

Bill Gatesek eta Paul Allenek sortu zuten Microsoft 1975ean. 1980an, IBMk Microsoft kontratatu zuen PC ordenagailuen sistema eragilea garatzeko: Microsoftek Tim Patersonen QDOS erosi zuen 50.000$-en truke, txukundu, eta MS-DOS izenarekin IBMri eskaini zion. Microsoftek edonori saldu ziezaiokeen MS-DOS — horrela bihurtu zen ordenagailu pertsonalen sistema eragilerik erabiliena.

1985ean, Windows 1.0 plazaratu zuen Microsoftek: ez zen sistema eragile berria, MS-DOSen gaineko bitartekari grafikoa baizik. 1990ean, Windows 3.0 arrakastatsuaren eskutik, Microsoft informatika-arloko enpresarik boteretsuena bihurtu zen.

1995eko Windows 95k, MS-DOSekiko menpekotasunari eutsi arren, publizitatearen bidez arrakasta itzela izan zuen. Ondorengo urteetan, AEBko justizia sailak hainbat salaketa jarri zizkion Microsofti monopolio-praktikengatik.

Windows 2000ekin, Microsoftek 16 biteko garapena baztertu eta "enbor bakarreko" bidea hartu zuen (Windows XP eta ondorengoak). Windows Vistak (2007) baliabide-eskakizun handiagoak zekartzan.

~/bestelakoak/apple.txt

Apple Macintosh

Steve Wozniakek eta Steve Jobsek sortu zuten Apple, 1976an. Apple IIk (1977) ordenagailu pertsonalen etorkizuna zehaztu zuen. Apple III (1980) diseinu-arazoek kaltetu zuten, eta hori izan zen Apple enpresaren lehen porrota handia.

Apple Lisak (1983) bitartekari grafikoa zuen ezaugarri nagusi, baina oso garestia zen (10.000$) eta gutxi saldu zen. Macintosh 1984ko urtarrilean atera zen; hasierako harrera ona izan arren, salmentak espero baino txikiagoak izan ziren, prezio altua (2.495$) eta software gutxi zirela eta. 1986an, autoedizioari esker, salmentak asko hazi ziren.

Gaur egun, Apple-k merkatuaren %5 baino gutxiago du, baina diseinurik dotoreena eskaintzen du. 2006ra arte PowerPC arkitektura erabili zuen; gaur egun Intel x86 mikroprozesadoreak ditu.
